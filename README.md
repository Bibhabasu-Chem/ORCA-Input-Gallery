# ⚗️ ORCA Input Gallery

A curated collection of input templates for **ORCA 5.0/6.0** quantum chemical calculations. 
These templates serve as starting points for exploring molecular properties, geometry optimizations, and thermodynamic calculations.

### 🗂️ Available Templates
- **Geometry Optimization (Basic):** Standard DFT geometry optimization.
- **Heavy Metal Complexes:** Templates tailored for Rare-Earth/Lanthanide systems using effective core potentials (ECP).
- **Thermodynamic Properties:** Frequency calculations for Gibbs free energy.
